## Goal

Replace all mocked API calls with real backend requests, align frontend types with the new `AuthResult` response shape, implement a transparent refresh-with-retry mechanism on 401, and ensure shop state is rehydrated after every login so navigation (dashboard vs onboarding) works correctly for returning users.

## Scope

### In Scope

- Type updates (`AuthResponse`, `User`, `ApiResponse<T>`, `Shop`)
- Remove mocks; wire real Axios calls for `register`, `login`, `google`, `createShop`
- New API functions: `refreshTokens`, `logoutApi`, `getMyShop`
- Axios client: request interceptor (attach access token); 401 response interceptor (refresh + retry)
- Auth store: `refreshToken` state, async `logout`, shop rehydration after login
- Shop store: `setShop` action
- `DashboardPage`: `GET /dashboard` on mount
- `LoginPage`: stale closure fix (`useShopStore.getState()` instead of hook capture)
- `RegisterPage`: smart redirect for Google OAuth path

### Out of Scope

- `name` field on `User` (separate task)
- Unit or integration tests
- Router / guard changes

## Implementation Steps

1. **Types** — Update `AuthResponse` to `{ access_token, refresh_token, user }` shape; remove `name` from `User`; add `ApiResponse<T>`; add `updatedAt` to `Shop`
2. **auth.api.ts** — Remove all mocks; call real endpoints with `apiClient`; add `refreshTokens` and `logoutApi` with `Authorization: Bearer <refreshToken>` header override
3. **shop.api.ts** — Remove mock; call `POST /shops`; add `getMyShop` → `GET /shops/mine`; unwrap `data.result`
4. **client.ts** — Change localStorage key from `auth-token` to `access_token`; add request interceptor; add 401 interceptor using raw `axios.post` to avoid infinite loop; set `config._retry` flag to prevent double-retry; on second failure: clear both tokens and redirect to `/login`
5. **auth.store.ts** — Add `refreshToken: string | null` to persisted state; update `loginWithEmail` and `loginWithGoogle` to call `getMyShop()` and `setShop`; make `logout` async (calls `logoutApi` → removes both localStorage keys → clears state)
6. **shop.store.ts** — Add `setShop(shop: Shop | null)` action
7. **DashboardPage** — Add `useEffect` calling `apiClient.get('/dashboard').catch(() => {})`; make `handleLogout` async
8. **LoginPage** — Remove `shop` hook subscription; rewrite `redirectAfterLogin` to call `useShopStore.getState().shop` at navigation time (avoids stale React closure)
9. **RegisterPage** — Import `useShopStore`; add `redirectAfterLogin` helper; replace hard-coded `navigate('/onboarding/shop')` in `handleGoogleCode` with `redirectAfterLogin()`
10. **RegisterShopPage** — Remove `{user?.name ? … : ''}` interpolation (field gone from type)
11. **Env** — Update `VITE_API_BASE_URL` to port `3001` (port `6000` is blocked by Chrome as an unsafe port)
